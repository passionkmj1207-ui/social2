# 썸네일 지침 — 월급노트

참고 스타일: 정사각형, 실사 사진 배경, 흰색 초굵은 고딕 헤드라인 2~3줄, 좌하단 계정명.

## 레이아웃 (1080×1080, 1:1)
- **배경**: **글의 내용을 관통하는 장면**의 사진이어야 한다. 기본은 Canva `generate-image`로 만든다(예: 집값 글 → 해질녘 한강변 아파트 단지, 금리 글 → 은행 창구·계산기, 월급 글 → 사무실 책상).
  - 글과 무관한 사진(예: 부동산 글에 병원 접수대)은 쓰지 않는다.
  - 사용자가 사진을 주는 경우에도 글 내용과 어울리는지 먼저 확인하고, 안 맞으면 알린다. 사진은 저장소에 올리지 않는다(`assets/thumbnail/`).
  - 글자가 들어갈 영역(좌측 중하단)은 어두운 오버레이(검정 0→85% 그라데이션)로 가독성을 확보한다.
  - 사진 안에 **다른 사람의 글자·로고·계정명이 박혀 있으면 쓰지 않는다.**
- **헤드라인**: 흰색, 가장 굵은 고딕, 2~3줄, 줄당 13자 이내, 좌측 정렬, 화면 중앙에서 약간 아래.
  - 숫자나 핵심 키워드 + 호기심을 남기는 구절. 결론을 다 말하지 않는다.
  - 글 제목을 그대로 쓰지 말고 **가장 궁금하게 만드는 부분만** 줄인다.
  - 예: "한강벨트 폭락설 / 숫자는 달랐다", "거래량 71% 증발 / 가격은 그대로?"
  - 다른 크리에이터의 문구를 따라 쓰지 않는다.
- **계정명**: 좌하단에 `@월급노트` (헤드라인의 약 1/3 크기, 흰색 굵게). 다른 계정명은 절대 남기지 않는다.
- 여백: 모든 변에서 최소 60px.

## 체크
- [ ] 계정명이 정확히 `@월급노트`인가
- [ ] 줄당 13자 이내, 3줄 이하인가
- [ ] 작은 크기(네이버 대표이미지 300px)에서도 읽히는가
- [ ] 배경 사진의 이용 권리를 확인했는가
- [ ] 헤드라인의 수치가 `claims.json` 검증 통과 값인가
